Global Scan / Backup / Restore

      

        Scan extracts chapters and mediainfo from disk into the scan database. Backup copies
        already-scanned data into the separate backup database. Restore writes backed-up
        chapters back into the MKV files. Runs across every library found under the mounted
        /libraries path.
      

      

        
        
        
      

    


    

      
Cleanup Steps

      

        Turn individual cleanup steps on or off. A disabled step is skipped entirely by both
        "Clean" and "Dry Run": it contributes no edit and no preview line.

Cleanup Default Audio Track

      

        When "Pick one default audio track by language priority" is enabled, exactly one audio
        track per file is marked default: the highest-priority language below that has a
        matching audio track. If none match, the first audio track in the file is used instead.

Chapter Analyzer Naming Schema

      

        Use {n} for the running number within that chapter type (e.g. multiple OP/ED in one
        episode) and {episode} for the episode number. The Episode chapter itself isn't
        listed here - its title is always plain "Episode".

Chapter Analyzer

      

        Detects Prologue/Opening/Episode/Ending/Epilogue chapters by matching episode audio against
        animethemes.moe OP/ED songs. Reached via the "Analyze Chapters" button on a season or episode.
      

      
      
      

        
      

    


    

      
Chapter Analyzer Cache

      

        Cached animethemes.moe theme audio expires automatically after the TTL above. Use this to force a
        clean re-download of everything right now (e.g. after a bad match caused by a corrupt download).

Danger Zone

      

        Permanently deletes every library, show, episode, chapter, and track metadata record
        from the backup database. The scan database is never touched, and files
        on disk are never touched.
