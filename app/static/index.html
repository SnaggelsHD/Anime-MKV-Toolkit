Global Scan / Backup / Restore

Scan extracts chapters and mediainfo from disk into the scan database. Backup copies already-scanned data into the separate backup database. Restore writes backed-up chapters back into the MKV files. Runs across every library found under the mounted /libraries path.

Cleanup Steps

Turn individual cleanup steps on or off. A disabled step is skipped entirely by both "Clean" and "Dry Run": it contributes no edit and no preview line.

Cleanup Default Audio Track

Danger Zone

Permanently deletes every library, show, episode, chapter, and track metadata record from the backup database. The scan database is never touched, and files on disk are never touched.
